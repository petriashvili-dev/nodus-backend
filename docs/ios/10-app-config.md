# Конфигурация приложения (app config)

Серверная сторона — [../12-app-config.md](../12-app-config.md).

Ссылки, минимальная версия и другие настроечные значения приходят с сервера и меняются без релиза приложения.

## Запрос

```http
GET /v1/app-config              (без авторизации)
If-None-Match: "<etag из прошлого ответа>"

200 ETag: "…"  { "values": { … }, "limits": { … }, "updated_at": "…" }
304            (ничего не изменилось — использовать сохранённое)
```

- Когда запрашивать: при запуске (до анонимного входа) и при каждом возврате из фона. Не блокировать интерфейс, кроме проверки минимальной версии.
- Последний ответ и его `ETag` хранить локально; при `304` использовать сохранённый.
- В приложение **зашиты значения по умолчанию** для всех ключей: первый запуск без сети, ошибка сервера, нет ключа, неверный тип — всё работает на них.
- Неизвестные ключи игнорировать. Ключ, тип которого не совпал с ожидаемым, — считать отсутствующим.

## Ключи `values`

Договорённость клиента и сервера; новый ключ — сначала сюда, потом в приложение и `config set`.

| Ключ | Тип | Что делает клиент |
|---|---|---|
| `links.privacy_policy` | string (URL) | ссылка в настройках и на экране согласия на AI |
| `links.terms` | string (URL) | условия использования |
| `links.support` | string (URL или `mailto:`) | «Написать в поддержку» |
| `links.app_store` | string (URL) | кнопка «Обновить» |
| `min_supported_version` | string (`1.2.0`) | версия приложения ниже — блокирующий экран «Обновите приложение» с `links.app_store` |
| `latest_version` | string (`1.4.0`) | версия ниже — ненавязчивое предложение обновиться, не чаще раза в день |

Версии сравнивать по числовым компонентам (`1.10.0` > `1.9.0`), не строкой. Нет `min_supported_version` — блокировки нет.

## `limits`

Только для чтения, совпадают с проверками сервера — использовать для счётчиков символов и проверки до отправки:

| Поле | Где |
|---|---|
| `ai_draft_text_max_chars` | текст диктовки перед `POST /ai/node-drafts` |
| `import_max_chars`, `import_ai_max_chars` | размер файла импорта (общий / для файлов других приложений) |
| `display_name_max_chars` | поле имени в профиле |

## Что сюда не относится

- Доступ пользователя к AI-функциям — `user.features` ([07](07-ai.md#доступ-к-ai-функциям-и-согласие)), а не `values`: конфиг одинаков для всех.
- Ничего секретного: эндпоинт публичный.
